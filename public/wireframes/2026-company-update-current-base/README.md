# 2026年会社資料 現行デザイン踏襲版ワイヤー

現行サイトのHTML・CSS・画像・セクション構成をそのまま画面化し、2026年版会社資料で変更が必要な文章、数値、事業分類のみを差し替えたワイヤーです。

## 方針

- ヒーロー、カード、見出し、余白、CTA、ヘッダー、フッターは現行デザインを維持する。
- 既に資料内容が反映されている蓄電池、バイオマス、ホッパー、AIデータセンターは構成を作り直さない。
- トップと事業紹介では、7つの詳細ページを維持しながら「5つの中核事業＋2つの専門ソリューション」として説明する。
- 沿革は「現在」を「2026年」に更新する。
- 風力発電事業には、既存レイアウトの間へ3つの事業戦略を追加する。
- 今回の資料に更新根拠がないページは変更しない。

## 出力対象

1. トップページ
2. 企業情報トップ
3. 会社概要
4. 沿革
5. 事業紹介
6. 蓄電池事業
7. バイオマス事業
8. 走行式集塵ホッパー事業
9. 風力発電事業
10. AIデータセンター事業
